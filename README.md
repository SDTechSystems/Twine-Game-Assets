# Twine Game Assets

An image asset repository for a Twine story project. It currently contains one PNG image, `assets/main.png`.

## Use

Download the image or reference its hosted location from a Twine passage using the image syntax supported by the story format. A relative reference requires the exported story and its asset folder to keep the same directory structure.

This repository does not contain the story source, a playable game or a build process.

## Asset rights

No reuse license is included. Confirm permission before redistributing the image or using it in another project.
